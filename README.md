# Lerato Bakehouse

## Project Description
Lerato Bakehouse is a bakery website designed to showcase bakery products, services and contact information. Customers can browse products and send enquiries through the website.

## Website Features
- Home page
- About Us page
- Services page
- Products page
- Enquiry form
- Contact form
- Website navigation
- Responsive design
- JavaScript functionality
- Search engine optimisation (SEO)

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Open the Website
1. Download or open the project folder.
2. Open the folder in Visual Studio Code.
3. Locate index.html.
4. Right-click index.html.
5. Select Open with Live Server.
6. The website will open in your browser.
